# PSWaker 0.1.0 RC1

The first release candidate of PSWaker, a PS4 homebrew port of *The Legend of
Zelda: The Wind Waker* (GameCube), built from your own disc.

This is a **private pre-release for testing**. It is the candidate for PS4
package validation ([#49](https://github.com/Jcanotorr06/pswaker/issues/49)) and
release readiness ([#50](https://github.com/Jcanotorr06/pswaker/issues/50)). It
is not a final or public release. Report problems as described in
[CONTRIBUTING.md](https://github.com/Jcanotorr06/pswaker/blob/v0.1.0-rc.1/CONTRIBUTING.md#reporting-a-problem).

## Requirements and quick start

You need Windows 10 or 11 x64, your own full raw dump of the USA `GZLE01`
revision 0 disc (`.iso` or `.gcm`, 1,459,978,240 bytes), a PS4 running GoldHEN
and a USB drive.

1. Install PSWaker (or extract the portable zip) and open it.
2. Select your disc image and an output folder, then select **Validate image**
   and **Create package**.
3. Copy the verified `.pkg` to the root of the USB drive and install it with
   **Settings → GoldHEN → Debug Settings → Package Installer**.
4. Launch PSWaker from the PS4 home screen.

The full steps are in the
[README](https://github.com/Jcanotorr06/pswaker/blob/v0.1.0-rc.1/README.md#creating-a-package).

## Known issues

- **Console acceptance is pending.** Final integrated console testing of the
  bundled program (01.13) hasn't finished, and no package created by the desktop
  app has been tested on the PS4 yet (#49).
- **Clean Windows testing is pending.** The app has only been tested on the
  development machine. Offline testing on clean Windows 10 and Windows 11 systems
  hasn't been done.
- **Pauses and frame pacing.** Expect brief pauses while areas load and the first
  time an effect appears. With an empty shader cache, frame pacing falls short of
  the target. Improving it is deferred to
  [#51](https://github.com/Jcanotorr06/pswaker/issues/51).
- **Shutdown not yet confirmed on 01.13.** The program includes a fix for an
  earlier crash when quitting after the memory card goes idle. Quit looked normal
  on screen with 01.12, but console logs haven't confirmed that shutdown completes
  internally, and 01.13 hasn't been checked yet.
- **One disc only.** Only the USA `GZLE01` revision 0 raw image is supported.
  Other regions and revisions, and scrubbed or compressed images, are rejected.
- **Limited route.** Only the route through Dragon Roost Island has been played.
  No claim is made about the rest of the game.
- **Windows x64 only, unsigned.** The installer and app are not code-signed, so
  Windows SmartScreen may warn.
- **Redistribution review is incomplete.** Some inherited SDK modules and stubs
  in the bundled program still have open licensing questions
  ([#47](https://github.com/Jcanotorr06/pswaker/issues/47)). Third-party notices
  and corresponding source for this release are deferred to #50.

## Not included

No game data, disc images, extracted game files, keys or complete packages. You
create your own package from your own disc.
