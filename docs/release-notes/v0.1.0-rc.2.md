# PSWaker 0.1.0 RC2

The second release candidate of PSWaker, a PS4 homebrew port of *The Legend of
Zelda: The Wind Waker* (GameCube), built from your own disc.

This is a **private pre-release for testing**, tracked in
[#91](https://github.com/Jcanotorr06/pswaker/issues/91). It is not a final or
public release. Report problems as described in
[CONTRIBUTING.md](https://github.com/Jcanotorr06/pswaker/blob/v0.1.0-rc.2/CONTRIBUTING.md#reporting-a-problem).

Compared with RC1, this candidate bundles program 01.14 with the approved
**game icon** and **launch splash**. Packaging and independent inspection now
validate both resources, and controlled content-failure packages retain them.
The approved PNGs are included in the repository for source builds; the Windows
executable icon was already included. Redistribution authorization and exact
artwork hashes are recorded in the
[release guide](https://github.com/Jcanotorr06/pswaker/blob/v0.1.0-rc.2/docs/RELEASING.md#artwork-redistribution-blocker).

## Tested platform

These are the project's previously tested baseline, not hardware acceptance of
this candidate. The bundled 01.14 binary has passed host package inspection but
has not been tested on the console. RC2 has not been tested on a clean Windows
system.

| | Previously tested baseline |
| --- | --- |
| Console | PS4 Slim, firmware 9.00, GoldHEN v2.4b18 |
| Game disc | USA *The Wind Waker*, `GZLE01`, revision 0 |
| PC | Windows 11 Pro x64, build 26200 (development machine, not a clean system) |

No broader compatibility is claimed.

## Requirements and quick start

You need Windows 10 or 11 x64, your own full raw dump of the USA `GZLE01`
revision 0 disc (`.iso` or `.gcm`, 1,459,978,240 bytes), a PS4 running GoldHEN
and a USB drive.

1. Install PSWaker (or extract the portable zip) and open it.
2. Select your disc image and an output folder, then select **Validate image**
   and **Create package**.
3. Copy the verified `.pkg` to the root of the USB drive and install it with
   **Settings → GoldHEN → Debug Settings → Package Installer**.
4. Launch PSWaker from the PS4 home screen.

The full steps are in the
[README](https://github.com/Jcanotorr06/pswaker/blob/v0.1.0-rc.2/README.md#creating-a-package).
Keep your disc image and complete package private, and preserve your saves
before performing fresh-install or update trials.

## Known issues

- **Console acceptance is pending.** Program 01.14 is a different binary from
  RC1's 01.13. Earlier gameplay observations do not establish acceptance of
  01.14, and no desktop-created package from RC2 has been tested on the PS4
  ([#49](https://github.com/Jcanotorr06/pswaker/issues/49)).
- **Artwork console checks are pending.** The packaged image hashes match the
  approved files, but the home-screen/library icon, splash visibility and
  first-frame handoff still need hardware observations. A separate versioned
  update must confirm that artwork, completed progress and a saved setting
  survive ([#85](https://github.com/Jcanotorr06/pswaker/issues/85)).
- **Clean Windows testing is pending.** Offline tests on clean Windows 10 and
  Windows 11 systems have not been completed for RC2.
- **Pauses and frame pacing.** Earlier builds showed brief pauses during area
  loading and first effects, with cold-cache frame pacing below target. This
  remains a known limitation; RC2 has no new console performance evidence
  ([#51](https://github.com/Jcanotorr06/pswaker/issues/51)).
- **Shutdown not yet confirmed on 01.14.** The program carries the earlier
  idle-memory-card shutdown fix, but console logs have not confirmed complete
  shutdown for this binary.
- **One disc only.** Only the USA `GZLE01` revision 0 raw image is supported.
  Other regions and revisions, and scrubbed or compressed images, are rejected.
- **Limited route.** Earlier gameplay reached Dragon Roost Island. No claim is
  made about the rest of the game or about replaying that route on 01.14.
- **Windows x64 only, unsigned.** The installer and app are not code-signed,
  so Windows SmartScreen may warn.
- **Public distribution review is incomplete.** Artwork permission is recorded,
  but there is no passing combined redistribution/readiness decision for RC2's
  native program, tools and runtime. Inherited module/stub rights, notices and
  corresponding-source obligations remain separate from artwork approval
  ([#47](https://github.com/Jcanotorr06/pswaker/issues/47),
  [#50](https://github.com/Jcanotorr06/pswaker/issues/50)). Closed ticket states
  alone do not demonstrate a passing decision.

## Not included

No game data, disc images, extracted game files, keys or complete packages. You
create your own package from your own disc. The approved shell artwork and
Windows executable icon are included.
