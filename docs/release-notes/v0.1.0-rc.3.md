# PSWaker 0.1.0 RC3

The third release candidate of PSWaker, a PS4 homebrew port of *The Legend of
Zelda: The Wind Waker* (GameCube), built from your own disc.

This is a **private pre-release for testing**, tracked in
[#117](https://github.com/Jcanotorr06/pswaker/issues/117). It is not a final or
public release. Report problems as described in
[CONTRIBUTING.md](https://github.com/Jcanotorr06/pswaker/blob/v0.1.0-rc.3/CONTRIBUTING.md#reporting-a-problem).

Compared with RC2, this candidate bundles program 01.18 with:

- Saved button bindings shared by gameplay and the port's applied-controls legend.
- A controls editor with occupied-target swaps, Apply and Discard. Pending edits
  take effect only after successful persistence.
- Restore Defaults with confirmation; defaults remain pending until Apply.
- Independent X/Y camera inversion switches, also used by first-person/item
  aiming through the documented native hooks.

The approved game icon, launch splash and Windows executable icon are retained.
Their redistribution authorization is recorded in the
[release guide](https://github.com/Jcanotorr06/pswaker/blob/v0.1.0-rc.3/docs/RELEASING.md#artwork-redistribution-blocker).
Original in-game GameCube prompts remain. The shader-seed delivery and
fresh-install action-preparation work tracked in
[#107](https://github.com/Jcanotorr06/pswaker/issues/107) is not included.

## Tested platform

These are the project's previously tested baseline, not hardware acceptance of
this candidate. The bundled 01.18 binary passed host program-package inspection;
RC3 has not been tested on the PS4 or a clean Windows system. The earlier 01.15
saved-controls observations do not establish acceptance of 01.18 or its editor
and inversion changes.

| | Previously tested baseline |
| --- | --- |

| Game disc | USA *The Wind Waker*, `GZLE01`, revision 0 |

No broader compatibility is claimed.

## Requirements and quick start

You need Windows 10 or 11 x64, your own full raw dump of the USA `GZLE01`
revision 0 disc (`.iso` or `.gcm`, 1,459,978,240 bytes), a PS4 running GoldHEN
and a USB drive.

1. Install PSWaker (or extract the portable zip) and open it.
2. Select your disc image and an output folder, then select **Validate image**
   and **Create package**.
3. Copy the verified `.pkg` to the root of the USB drive and install it with
   **Settings > GoldHEN > Debug Settings > Package Installer**.
4. Launch PSWaker from the PS4 home screen. Use Touchpad to open the port menu;
   edit Controls and select Apply to save a new layout or inversion preferences.

The full steps are in the
[README](https://github.com/Jcanotorr06/pswaker/blob/v0.1.0-rc.3/README.md#creating-a-package).
Keep your disc image and complete package private, and preserve your saves
before performing fresh-install or update trials.

## Known issues

- **Console acceptance is pending.** Program 01.18 differs from RC2's 01.14.
  Earlier gameplay observations do not establish acceptance of this binary,
  and no desktop-created package from RC3 has been tested on the PS4
  ([#49](https://github.com/Jcanotorr06/pswaker/issues/49)).
- **Configurable controls need integrated hardware validation.** Editor,
  Apply/Discard, Restore Defaults, camera/aiming contexts and separate
  update/cache/storage checks remain pending for this binary
  ([#98](https://github.com/Jcanotorr06/pswaker/issues/98)). Original in-game
  GameCube prompts do not follow the applied layout
  ([#79](https://github.com/Jcanotorr06/pswaker/issues/79)).
- **Artwork console checks are pending.** Packaged images match the approved
  files, but home-screen/library visibility, splash timing, first-frame handoff
  and preservation across a separate versioned update still need observations
  ([#85](https://github.com/Jcanotorr06/pswaker/issues/85)).
- **Clean Windows testing is pending.** Offline testing on clean Windows 10
  and Windows 11 systems has not been completed for RC3.
- **Pauses and frame pacing.** Expect brief area-loading and first-effect
  pauses. Earlier empty-cache runs fell short of the frame-pacing target;
  RC3 supplies no new console performance evidence
  ([#51](https://github.com/Jcanotorr06/pswaker/issues/51)).
- **Shutdown not yet confirmed on 01.18.** The program carries the earlier
  idle-memory-card shutdown fix, but logs have not confirmed complete shutdown
  for this binary.
- **One disc only.** Only the USA `GZLE01` revision 0 raw image is supported.
  Other regions/revisions and scrubbed or compressed images are rejected.
- **Limited route.** Earlier gameplay reached Dragon Roost Island. No claim
  is made about the rest of the game or replaying that route on 01.18.
- **Windows x64 only, unsigned.** The installer and app are not code-signed,
  so Windows SmartScreen may warn.
- **Public distribution review is incomplete.** Artwork permission does not
  establish a passing combined native-program/tool/runtime readiness decision.
  Inherited module/stub rights, notices and corresponding-source obligations
  remain separate
  ([#47](https://github.com/Jcanotorr06/pswaker/issues/47),
  [#50](https://github.com/Jcanotorr06/pswaker/issues/50)). Closed ticket states
  alone do not demonstrate a passing decision.
