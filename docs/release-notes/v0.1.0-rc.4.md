# PSWaker 0.1.0 RC4

## Summary

The fourth release candidate of PSWaker, a PS4 homebrew port of *The Legend of
Zelda: The Wind Waker* (GameCube), built from your own disc.

This is a **private pre-release for testing**, tracked in
[#130](https://github.com/Jcanotorr06/pswaker/issues/130). Report problems through
[CONTRIBUTING.md](https://github.com/Jcanotorr06/pswaker/blob/v0.1.0-rc.4/CONTRIBUTING.md#reporting-a-problem).

Compared with RC3, this candidate bundles program 01.20 and:

- Automatically includes the validated 287-description shader seed when the
  desktop app creates a complete package. Missing or incompatible assets stop
  packaging; there is no extra player setup.
- Prepares seeded shader configurations before gameplay, with startup progress
  and explicit error handling. Compatible runtime caches can be reused.
- Records a successful full installed disc-image check for the current build
  and package identity, avoiding that full check on later launches. A changed
  build or invalid record requires a new check.
- Includes the bounded, owner-accepted Outset evidence for the normally
  CLI-assembled 01.20 package. Recorded cold shader preparation took 14.621 s;
  the cold sample maximum fell from 333.669 ms to 50.114 ms with zero recorded
  missing-pipeline waits. These observations have the limits below.

Configurable controls, Apply/Discard, confirmed Restore Defaults, independent
camera/aiming inversion and the approved artwork are retained. Original in-game
GameCube prompts remain. The source changes also deepen the complete-package
workflow and add GitHub issue forms.

## Requirements and quick start

You need Windows 10 or 11 x64, your own full raw dump of the USA `GZLE01`
revision 0 disc (`.iso` or `.gcm`, 1,459,978,240 bytes), a PS4 running GoldHEN
and a USB drive.

1. Install PSWaker (or extract the portable zip) and open it.
2. Select your disc image and an output parent folder, then select
   **Validate image** and **Create package**. The required seed is included
   automatically.
3. Copy the verified `.pkg` to the USB drive and install it with
   **Settings > GoldHEN > Debug Settings > Package Installer**.
4. Launch PSWaker from the PS4 home screen. Allow the initial image check and
   shader preparation to complete before gameplay. Touchpad opens the port menu.

The full steps are in the
[README](https://github.com/Jcanotorr06/pswaker/blob/v0.1.0-rc.4/README.md#creating-a-package).
Keep your disc image and complete package private. Preserve your saves before
fresh-install, cache or update trials.

## Known issues

- **Final integrated console acceptance is pending.** The #112 decision accepts
  the returned Outset evidence as supplied, not a release-wide pass or testing
  of RC4 desktop-created packages
  ([#49](https://github.com/Jcanotorr06/pswaker/issues/49)).
- **Preparation trades startup time for less runtime work.** Full cold shader
  preparation took 14.621 s in the identified return. Recorded configurations
  cover only the bounded captured route. Other scenes, equipment and actions
  may create pipelines during gameplay and pause.
- **Performance and lifecycle evidence has gaps.** Approximately 50 ms
  intervals remain, including more in the changed warm sample. Physical
  presentation timing, normal recorder shutdown, actual first-action timing
  and video, visible preparation progress, incompatible-update behavior,
  save/settings preservation and detailed correctness checks remain unverified.
  Both analyzer summaries retain exit 2 and `target_met: false`. No verified
  numerical performance pass, broader Outset/forest or full-game coverage is
  claimed. See the
  [assessment](https://github.com/Jcanotorr06/pswaker/blob/v0.1.0-rc.4/evidence/ps4/action-validation-112/REPORT.md)
  and [#51](https://github.com/Jcanotorr06/pswaker/issues/51).
- **Configurable controls need integrated hardware validation.** Editor,
  Apply/Discard, Restore Defaults and camera/aiming contexts remain separate
  checks ([#98](https://github.com/Jcanotorr06/pswaker/issues/98)). Original
  in-game GameCube prompts do not follow the applied layout
  ([#79](https://github.com/Jcanotorr06/pswaker/issues/79)).
- **Artwork console checks are pending.** Packaged artwork matches the approved
  files, but visibility, splash handoff and preservation across a separate
  versioned update still need observations
  ([#85](https://github.com/Jcanotorr06/pswaker/issues/85)).
- **Clean Windows testing is pending.** RC4 has not completed offline testing
  on clean Windows 10 and Windows 11 systems.
- **Limited route and disc support.** Earlier gameplay reached Dragon Roost
  Island. No full-game acceptance or replay of that entire route on 01.20 is
  claimed. Only USA `GZLE01` revision 0 full raw images are supported; other
  regions/revisions and scrubbed or compressed images are rejected.
- **Windows x64 only, unsigned.** The app and installer are not code-signed,
  so Windows SmartScreen may warn.
- **Public distribution review is incomplete.** Artwork authorization does not
  supply a passing combined program/tool/runtime readiness decision. Inherited
  module/stub rights, notices and corresponding-source obligations remain
  separate ([#47](https://github.com/Jcanotorr06/pswaker/issues/47),
  [#50](https://github.com/Jcanotorr06/pswaker/issues/50)). Closed ticket states
  alone do not demonstrate a passing decision. Keep this release private.

## Not included

No game data, disc images, extracted game files, keys or complete packages.
Create your own package from your own disc. The approved shell artwork,
Windows executable icon and private validated shader-description asset are
included in the Windows bundles. Build outputs and seed contents stay out of git.
